# Cloudflare Pages Deployment Checklist

## Pre-Deployment

- [x] Project builds successfully (`npm run build`)
- [x] `_redirects` file configured for SPA routing
- [x] `_headers` file configured for security headers and caching
- [x] `wrangler.toml` configured
- [x] `package.json` has correct homepage field
- [x] Environment variables template created (`.env.cloudflare`)
- [x] Build output directory: `build/`

## Git Setup

- [ ] Initialize git repository (if not already)
  ```bash
  git init
  git add .
  git commit -m "Initial commit: Ready for Cloudflare Pages deployment"
  ```

- [ ] Create GitHub repository
- [ ] Push to GitHub
  ```bash
  git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
  git branch -M main
  git push -u origin main
  ```

## Cloudflare Pages Setup

### Step 1: Connect GitHub
- [ ] Go to [Cloudflare Dashboard](https://dash.cloudflare.com/)
- [ ] Navigate to **Pages**
- [ ] Click **Create a project**
- [ ] Select **Connect to Git**
- [ ] Authorize GitHub
- [ ] Select your repository

### Step 2: Configure Build
- [ ] Framework preset: **None**
- [ ] Build command: `npm run build`
- [ ] Build output directory: `build`
- [ ] Environment variables (optional):
  - Add `REACT_APP_API_URL` if using external API

### Step 3: Deploy
- [ ] Review settings
- [ ] Click **Save and Deploy**
- [ ] Wait for first deployment to complete

### Step 4: Custom Domain (Optional)
- [ ] Go to Pages project → **Custom domains**
- [ ] Add your domain
- [ ] Follow DNS configuration steps
- [ ] Wait for SSL certificate (usually instant)

## Post-Deployment

- [ ] Test the deployed site
- [ ] Verify all routes work (SPA routing)
- [ ] Check browser console for errors
- [ ] Test on mobile devices
- [ ] Verify Security headers (inspect in DevTools)

## Continuous Deployment

- [ ] Every push to `main` triggers automatic deployment
- [ ] Preview deployments for pull requests (if enabled)
- [ ] Failed deployments notify you via Cloudflare

## Performance Testing

- [ ] Check Cloudflare Analytics
- [ ] Monitor Core Web Vitals
- [ ] Test asset caching (static files cached for 1 year)
- [ ] Verify index.html is cache-busted

```
├── CLOUDFLARE_DEPLOYMENT.md ← This deployment guide
└── ...
```

## Troubleshooting

### 404 errors on navigation
- Verify `_redirects` file is in the build output
- Check that /* line redirects to /index.html

### Styles not loading
- Check `_headers` cache control settings
- Ensure Tailwind CSS build included correct output

### Environment variables not working
- Set them in Cloudflare Dashboard → Pages → Settings
- Use `REACT_APP_` prefix for frontend variables
- Rebuild to apply changes

### Deployment fails
- Check build command output in Cloudflare
- Verify Node.js version compatibility
- Ensure all dependencies in package.json
